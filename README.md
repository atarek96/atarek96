## 📌 Highlighted Projects

### 🗂 BIRT Material Delivery Note Report
> **IBM Maximo · SQL · BIRT Report Designer**
Designed and developed a BIRT report for Material Delivery Note (MDN) transactions in Maximo. Wrote complex SQL queries joining `MATRECTRANS`, `ITEM`, `INVENTORY`, and `WORKORDER` tables with `onFetch` script bindings for dynamic data rendering.

### 📦 Maximo Data Migration & Integration
> **MXLoader · MIF · XML**
Led XML-based data import/export operations using MXLoader and MIF object structures. Resolved alias conflicts and BMXAA error codes, and structured multi-job import sequences for bulk asset and specification data loads.

### 📊 Sales Data Analysis & Power BI Dashboard
> **Python · Power BI**
Cleaned and merged multi-source sales data using Pandas. Built an interactive Power BI dashboard revealing top revenue cities (33% of total) and the dominant payment method (Credit Card — 43%).

### 🤖 Image Classification — CNN vs ANN
> **Python · TensorFlow · Keras**
Trained a CNN achieving 94%+ accuracy on CIFAR-10 and an ANN achieving 97%+ accuracy on MNIST. Implemented full preprocessing pipeline, one-hot encoding, and comparative training metrics visualization.

### 🏠 House Price Prediction
> **R · Linear Regression**
Built a manual regression model from scratch: calculated coefficients, constructed ANOVA table, derived confidence intervals, and visualized predicted vs actual values.
